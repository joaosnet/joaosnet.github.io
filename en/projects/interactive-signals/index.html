Context & contribution

03 / Engineering choices

Engineering choices

01

Canvas 2D with 3D projection

Custom 120 FPS rendering pipeline using Three.js camera projection directly into Canvas 2D, avoiding heavy plotting packages.

02

Support and regime calculation

Algorithm that computes signal support intervals and derives exact integration limits for each segment.

03

Textbook reference cases

Analytical examples based on Oppenheim and Lathi, with step-by-step graphical verification.

Project limitations

Runs entirely in the browser; maintaining 120 FPS depends on the user's hardware graphics support.
